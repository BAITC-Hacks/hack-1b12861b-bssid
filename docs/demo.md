# Демо на пять минут

Примерные gid не зашиты в программу: после каждого запуска три узла выбираются по ролям и приоритету в `data/output/demo_nodes.md`.

| Время | Действие | Что показать |
|---|---|---|
| 0:00–0:45 | `python start.py`, открыть localhost:3000 | Полный запуск по parquet, время в отчёте, 2248 узлов |
| 0:45–1:15 | Обзор, фильтр сообщества, окраска кластеров | 90 кластеров, 8 с несколькими seed; 5 из 8 устойчивы по строгому критерию |
| 1:15–2:15 | Первый coordinator из demo_nodes.md | Конкретные суммы/степени и порог; гипотеза, а не доказанный организатор |
| 2:15–3:00 | transit из demo_nodes.md | Вход, выход, коэффициент 0.8–1.2; нет доказательства временного транзита |
| 3:00–3:45 | terminal из demo_nodes.md | depth<4, вход выше порога; почему это не относится к 444 обрезанным узлам |
| 3:45–4:30 | Произвольный gid жюри, переход по связи | Поиск по точной строке, карточка, правило, стрелки, числовое evidence |
| 4:30–5:00 | «Пересчитать данные», CSV | Асинхронный статус, обновлённый граф, три выгрузки и ограничения |

Перед выступлением проверить `python -m unittest discover -s tests -v` и `node --test server/test/api.test.js`. В браузере требуется WebGL. Для работы без сети заранее установить зависимости и выполнить сборку. Не запускать демонстрационный пересчёт параллельно с внешним CLI-процессом, пишущим в ту же папку.
